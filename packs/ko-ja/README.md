# Korean → Japanese word packs

This directory contains approved Japanese-learning word packs for Korean
speakers, grouped by category.

Use lowercase English letters, numbers, and hyphens for new directories and
files. For example:

```text
packs/ko-ja/travel/airport.json
packs/ko-ja/daily-life/greetings.json
```

Read the repository's [contribution guide](../../CONTRIBUTING.md) before adding
a pack.
